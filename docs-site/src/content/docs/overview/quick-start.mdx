This walkthrough uses the web app at [restura.dev](https://restura.dev/). The desktop app works the same way and adds native-only features such as Kafka, MQTT, mTLS, and the AI assistant.

## Send your first request

<Steps>

1. **Open Restura.** A fresh HTTP request tab is already open.

2. **Type a URL.** Try `https://echo.restura.dev/get?hello=world`. This is the public echo server bundled with Restura — useful for poking around.

3. **Hit Send** (or `Cmd+Enter` / `Ctrl+Enter`). You'll see the response on the right: status, headers, timing, and a pretty-printed body.

4. **Switch the method.** Click `GET` and pick `POST`. Open the **Body** tab, choose **JSON**, paste `{"hello":"world"}`, and send. The echo server reflects it back.

</Steps>

## Save it to a collection

<Steps>

1. Click the **Save** button (top right of the request).
2. Pick **New collection**, name it `Playground`, then save.
3. The request now appears in the **Collections** sidebar on the left.

</Steps>

You can drag requests between folders, duplicate them, or right-click for more options.

## Add an environment

Environments let you swap variables (like `{{base_url}}`) between staging and production with one click.

<Steps>

1. Click the environment selector (top right, says "No environment").
2. **Manage environments** → **New environment** → name it `local`.
3. Add a variable: name `base_url`, value `https://echo.restura.dev`.
4. Back in the request, change the URL to `{{base_url}}/get`. Send.

</Steps>

The placeholder resolves at send time. Switch environments → same request, different upstream.

## Try another protocol

Click the protocol picker (left of the URL, says `HTTP`) and pick a different one:

- **GraphQL** — try `https://echo.restura.dev/graphql` with the query `{ echo(message: "hello") { message timestamp } }`.
- **gRPC** — point at `https://echo.restura.dev`, load the schema with server reflection, and call `echo.v1.EchoService` → `UnaryEcho` (or `ServerStreamingEcho`). The echo server speaks the Connect protocol. For other servers you need reflection or a `.proto` file.
- **WebSocket** — connect to `wss://echo.restura.dev/ws`, send a frame, watch it echo back.
- **SSE** — connect to `https://echo.restura.dev/sse` and watch the live stream.
- **MCP** — point at any HTTP-based MCP server.

Each protocol has its own guide with the full feature list — start with [HTTP](/protocols/http/), [GraphQL](/protocols/graphql/), or [gRPC](/protocols/grpc/), and check the [capability matrix](/reference/capability-matrix/) for what differs between web and desktop.

Prefer not to type? Each protocol page has a **Try it** panel with a ready-made sample collection for the echo server — [HTTP](/samples/http.opencollection.json), [GraphQL](/samples/graphql.opencollection.json), [gRPC](/samples/grpc.opencollection.json), [WebSocket](/samples/websocket.opencollection.json) and [SSE](/samples/sse.opencollection.json). In the web app, download one and import it with **Import → OpenCollection**; on desktop, **Open in Restura desktop** on the protocol page hands the sample to the import dialog, which shows the source and only downloads it after you choose **Download preview**.

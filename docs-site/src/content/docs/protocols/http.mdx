The bread and butter. Restura's HTTP client supports every method, every body shape, and gives you the full request/response timeline with timing breakdown.

## Methods

GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS, and any custom verb you type.

## Body types

- **None**
- **JSON** — the **Beautify** button formats the body and keeps `{{variable}}` references exactly as written, including bare ones like `"id": {{id}}`.
- **Text** — plain text, UTF-8.
- **XML** — syntax highlighted; sent with `Content-Type: application/xml` unless you set your own.
- **Form data (`multipart/form-data`)** — supports file inputs.
- **Form URL-encoded (`application/x-www-form-urlencoded`)** — edit as a key/value table, or switch to **Text** to edit the encoded string directly.
- **Binary** — drag in any file; Restura reads it as a stream.
- **Protobuf** — paste base64 or upload a binary; helpful for testing gRPC-style endpoints behind a JSON adapter.

## Headers, params, cookies

- **Query parameters** — kept in sync with the URL. Type or paste `?a=1&b=2` into the URL bar and the rows appear in **Params**; edit a row and the URL updates. Disabled rows stay in the table and are left out of the URL.
- **Paste a cURL command** into the URL bar to fill in the method, URL, headers and body. A toast offers **Undo**.
- **Bulk edit** — switch params or headers to a text view with one `key: value` per line. Prefix a line with `//` to disable it.
- **Variables** — hover a `{{variable}}` in the URL or a param value to see its value and where it comes from (environment, collection, folder, globals). Secret values are masked.
- **Headers** — autocompletion for standard names + values where applicable.
- **Cookies** — per-request override, plus a session-wide cookie jar on desktop.

## Authentication

Every auth scheme Restura supports works on HTTP: Bearer, Basic, API Key, OAuth 2.0 (all four common grants with PKCE), OAuth 1.0a (HMAC-SHA1), AWS Signature v4, Digest, NTLM, WSSE, and mTLS on desktop. See the [auth guide](/guides/auth/).

## Code generation

Click the `</>` icon next to the URL, or run **Copy as cURL** from the command palette. Snippets resolve variables from every scope and include the request's auth, including auth inherited from a folder or collection.

**Mask secrets** is on by default: secret variables stay as `{{name}}` references and credentials become placeholders such as `<token>`. Values stored in the desktop keychain are never printed. Auth that's computed per request (Digest, NTLM, AWS Signature v4, OAuth 1.0, WSSE) and binary bodies are noted as comments rather than generated. Multipart form-data is generated for cURL, Python and JavaScript. The last language you picked is remembered.

Available languages:

- `curl`.
- Python (`requests`).
- JavaScript (`fetch`).
- Node.js (`axios`).
- Go (`net/http`).
- Ruby.
- PHP.
- More languages added in releases — open an issue if your stack is missing.

## History & timing

Every send is recorded to history with status, timing, request hash, and a quick way to **resend**. Per-response, you get:

- **Status** and status text. Hover or focus the status for a plain-language explanation.
- **Timing**: the **Timeline** tab breaks the total into phases.
  - Everywhere: *Waiting* (time to response headers, including any redirects), *Download* (the body), and the remaining overhead. On the web this is the round trip to the Restura *Proxy*; on desktop it's *App* time such as scripts and IPC.
  - Desktop only: *DNS* and *Connect + TLS* are also measured for direct connections. They're left out when a proxy is used, because they would describe the connection to the proxy.
- **Size**: the decoded body size.
- **Headers**: filter by name or value; *Copy all* copies one `Name: value` line per value.
- **Body**:
  - pretty-printed JSON with a collapsible **Tree** view (*Copy path* gives a JSONPath you can paste into the JSONPath box)
  - syntax-highlighted XML
  - **Download**, saved under the request's name with the right extension
- **Compare with previous**: once a request has an earlier response in history, a toolbar button diffs the two side by side.
- **Cancel**: while a request runs, the response panel shows the elapsed time and a **Cancel** button. GraphQL can be cancelled too.

## Worth knowing

- The **SSRF guard** blocks requests to RFC 1918, RFC 6598 (CGNAT), link-local, loopback, IPv4-mapped IPv6, cloud metadata endpoints (`169.254.169.254`), and IPv6 unique-local — unless explicitly allowed (e.g. `ENVIRONMENT=development` in the Worker, `--allow-localhost` in the CLI).
- The **desktop client** also enforces a **pre-flight DNS guard** against DNS-rebind: hostnames are resolved before connecting, and every record is validated.
- **Custom CAs**, **disabled TLS verification**, **client certificates (mTLS)**, and **SOCKS4/5** proxies are <Badge text="desktop only" variant="caution" /> — the browser sandbox doesn't expose them.
